## Authentication
This provider requires authentication.
- **webhook_url**: xMatters Flow Designer incoming webhook URL (required: True, sensitive: True)



## In workflows

This provider can be used in workflows.


As "action" to make changes or update data, example:
```yaml
actions:
    - name: Notify via xMatters
      provider: xmatters
      config: "{{ provider.my_provider_name }}"
      with:
        message: {value}   # Alert body / details (required)
        title: {value}     # Alert subject (default: "Keep Alert")
        severity: {value}  # Severity level sent to xMatters (default: "high")
```
