## Authentication
This provider requires authentication.
- **api_key**: Honeybadger API key (required: True, sensitive: True)
- **project_id**: Honeybadger project ID (required: True, sensitive: False)

Certain scopes may be required to perform specific actions or queries via the provider. Below is a summary of relevant scopes and their use cases:
- **honeybadger:notify**: Send error notices to Honeybadger (mandatory) 



## In workflows

This provider can be used in workflows.



As "action" to make changes or update data, example:
```yaml
actions:
    - name: Notify honeybadger
      provider: honeybadger
      config: "{{ provider.my_provider_name }}"
      with:
        message: {value}  # The error message to report.
        error_class: {value}  # The error class name. Defaults to "Alert".
```
