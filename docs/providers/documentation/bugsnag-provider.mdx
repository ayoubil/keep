## Connecting with the Provider

To use the Bugsnag provider, you need a Bugsnag API key.

### API Key

1. Log in to your [Bugsnag dashboard](https://app.bugsnag.com/).
2. Navigate to **Settings** -> **Projects** and select your project.
3. Go to **Project Settings** and copy the **API Key** shown at the top.
