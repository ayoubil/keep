## Overview

The Better Stack provider integrates Keep with Better Stack's incident management platform, allowing you to create and manage incidents through Keep workflows.

<AutoGeneratedSnippet />

## Connecting with the Provider

### API Token

To obtain a Better Stack API token:

1. Log in to your [Better Stack](https://betterstack.com) account.
2. Navigate to **Settings** → **API**.
3. Copy your existing API token or generate a new one.

### Creating Incidents

The provider creates incidents via the Better Stack Uptime API (`POST /api/v2/incidents`). You can specify the incident name, status, and start time.

Supported status values: `investigating`, `identified`, `monitoring`, `resolved`.

For more details, refer to the [Better Stack API Documentation](https://betterstack.com/docs/uptime/api/list-all-existing-incidents/).
