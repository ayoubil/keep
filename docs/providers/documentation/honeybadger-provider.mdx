## Connecting with the Provider

To use the Honeybadger provider, you need an API key and your project ID.

### API Key

1. Log in to your [Honeybadger account](https://app.honeybadger.io/).
2. Navigate to **Settings** -> **API Keys**.
3. Copy your **Write-only API key** (used for reporting errors).

### Project ID

Your project ID is visible in the URL when you open a project in the Honeybadger dashboard:
`https://app.honeybadger.io/projects/{project_id}/faults`
