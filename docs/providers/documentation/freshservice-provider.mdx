## Overview

The Freshservice provider allows Keep to open incidents and tickets directly in Freshservice via the v2 REST API. It supports configurable priority and maps Keep alerts to Freshservice incidents automatically.

<AutoGeneratedSnippet />

## Connecting with the Provider

1. Log in to your Freshservice account as an administrator.
2. Navigate to **Profile Settings** (top-right avatar menu).
3. Copy the **API Key** shown on the profile page.
4. Use your Freshservice subdomain as the **domain** field (e.g. `yourcompany.freshservice.com`).
5. Provide the email of the agent or requester that should appear on created tickets.
