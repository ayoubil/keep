## Connecting with the Provider

1. Log in to your [Atlassian Statuspage](https://www.atlassian.com/software/statuspage) account.
2. Go to **API** in the top navigation bar.
3. Click **Create key** to generate a new API key. This is your `Statuspage API key (OAuth token)`.
4. To find your **Page ID**, go to your page settings. The page ID is shown under **Page Information**.
