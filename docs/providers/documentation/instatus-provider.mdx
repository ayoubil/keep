## Connecting with the Provider

1. Log in to your [Instatus](https://instatus.com) account.
2. Go to **Account Settings** and navigate to **API Keys**.
3. Generate a new API key and copy it. This is your `Instatus API key`.
4. To find your **Page ID**, open your status page dashboard. The page ID appears in the URL: `https://dashboard.instatus.com/YOUR_PAGE_ID/`.
