## Overview

The xMatters provider posts alert payloads to an xMatters Flow Designer incoming webhook. This allows Keep to trigger xMatters flows, notify on-call responders, and drive incident response workflows directly from Keep alerts.

<AutoGeneratedSnippet />

## Connecting with the Provider

1. In xMatters, open **Flow Designer** and select or create a flow.
2. Add an **Incoming Webhook** trigger to the canvas.
3. Configure the trigger's form fields to include `subject`, `body`, and `severity` properties.
4. Copy the webhook URL from the trigger's settings panel.
5. Paste that URL as the **webhook_url** when configuring this provider in Keep.
