## Overview

The Rootly provider integrates Keep with Rootly's incident management platform, allowing you to create incidents through Keep workflows with support for severity levels and descriptions.

<AutoGeneratedSnippet />

## Connecting with the Provider

### API Key

To obtain a Rootly API key:

1. Log in to your [Rootly](https://rootly.com) account.
2. Navigate to **Settings** → **API Keys**.
3. Click **New API Key** and copy the generated key.

### Creating Incidents

The provider creates incidents via the Rootly REST API (`POST /v1/incidents`). You can specify the incident title, description, and severity.

Supported severity values: `critical`, `high`, `medium`, `low`.

For more details, refer to the [Rootly API Documentation](https://rootly.com/api).
